INSTALLATION
1. Placez votre image professionnelle dans ce dossier sous le nom exact : zongo-photo.jpg
2. Copiez votre fichier cv-boureima-zongo.html dans ce dossier.
3. Remplacez VOTRE-NOM-UTILISATEUR dans index.html, robots.txt et sitemap.xml par votre identifiant GitHub.
4. Publiez tous les fichiers à la racine de votre dépôt GitHub Pages.

OPTIMISATION PHOTO CONSEILLEE
- Format JPG ou WebP
- Largeur 800 à 1200 px
- Poids idéal inférieur à 250 Ko
